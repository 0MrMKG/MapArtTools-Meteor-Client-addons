0.8.0 Release / 0.8.0 版本发布

两种构建 / Build variants
- 无反作弊版本：独立 Fabric 模组，保留裁剪后的 Meteor GUI 控件，无须完整 Meteor Client。
- master：Meteor Client 插件，保留 Meteor 依赖与原有插件入口。
- 两版版本号统一为 0.8.0；运行方式分别维护。

界面 / Interface
- 参考本地 Catppuccin Addon 的 Mocha 深色风格，使用绿色强调色、圆角、分层背景与柔和阴影。
- 改进按钮反馈、勾选显示、滑条与设置分组，保留中文字体。
- 需要玩家手动登记的箱子、原点和工作站坐标集中在“位置设置”。

画布方向 / Canvas directions
- 在画布原点后加入 X、Z 两个可点击切换的方向按钮。
- 默认 X+ / Z+，保持原有坐标与蓝图行为；可独立切换为 X- / Z-。
- 方向围绕登记原点作用于蓝图坐标，保留子区域偏移与负尺寸，不自动居中。
- 绘制、蛇形行走、复查、地图中心与地图网格对齐统一使用变换后的画布。
- 保存方向配置；原默认方向的断点保持兼容。修改已有批次方向后需重新初始化。

补货 / Restocking
- 移除地图画余料箱登记、列表、定期回存与绕路流程。
- 补货前按当前条带优先、返程条带其次的顺序保留材料，整组丢出多余颜色。
- 向路线侧面丢弃并等待背包同步后重新计算补货，减少重新捡回的情况。
- 保留食物、工具与地图原料；全自动模式为地图和玻璃板预留槽位。
- 保留生产箱对应颜色至少一组地毯的既有保底规则。

验证 / Validation
- 两版分别执行构建与回归检查；新增四方向矩阵测试和圆角绘制几何测试。
- 游戏内界面检查此前被 Esc 中止，完整显示效果及服务器实测仍需验证。
